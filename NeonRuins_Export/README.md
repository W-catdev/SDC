## 🚀 快速开始

### 玩游戏
```bash
# 方式 1：直接双击
打开 SDC/index.html（推荐用 Chrome / Edge / Firefox）

# 方式 2：本地服务器（更稳）
cd SDC
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

### 跑测试（需 Node.js ≥ 14）
```bash
cd tests
node test-static.js          # 静态功能
node test-reload-bug.js      # 装填状态机
node test-loot-ui.js         # v1.7 LOOT-UI 专项
```

## ✨ 当前版本特性（v1.0 + v1.7）

- **战斗系统**：7 种武器、后坐力系统、子弹物理、肢体命中、爆头机制
- **敌人 AI**：6 种类型（变异者/掠夺者/精英/隐行者/爆裂者/装甲兵）
- **搜刮系统（v1.7 升级）**：5 种容器（普通/金库/遗骸），拾取界面（不再散落地面）
- **撤离系统**：3 撤离点、5 秒停留、飞船动画
- **库存/装备**：三列 UI、装备槽、负重、localStorage 持久化
- **角色成长**：等级系统、属性加成、成就系统（21 个）
- **音频系统**：8 种程序化音效、5 层自适应 BGM
- **任务系统**：5 种任务类型
- **环境效果**：粒子、震屏、电影滤镜、动态难度
