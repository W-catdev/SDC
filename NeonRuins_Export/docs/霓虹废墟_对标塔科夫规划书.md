# 《霓虹废墟 · Neon Ruins》对标塔科夫详细规划书（v2.0 草案）

> 本文档基于对《逃离塔科夫》（Escape from Tarkov）核心系统、搜打撤品类最新研究，

> 给出一份对标塔科夫、可分阶段落地的详细开发规划。

## 0. 摘要：为什么对标塔科夫、怎么对标

### 0.1 品类格局（2025-2026）
- 搜打撤（Extraction Shooter）已从"小众硬核"演变为"百亿赛道"：2025 年《暗区突围》+《三角洲行动》流水合计已破百亿。
- 鼻祖《逃离塔科夫》于 2025-11-15 发布 1.0 正式版并登陆 Steam，2026 年开始走"轻量化"路线（降低门槛、扩新玩家）。
- 品类内部分化明显：
  - 硬核拟真路线：塔科夫本尊、《灰区战争》、《Exoborne》
  - 大众化路线：《三角洲行动》、《暗区突围》（移动端）
  - 休闲社交路线：《超自然行动组》、《逃离鸭科夫》

### 0.2 塔科夫的不可替代内核（必须对标的 5 个支柱）
1. **局内冒险 + 局外成长的强绑定** —— 局内不带出 = 永久损失
2. **"资产博弈"心理引擎** —— Gear Fear 与多巴胺的正反同源
3. **封闭循环经济** —— 没有"死物"，每件垃圾都有去处（商人/藏身处/任务）
4. **深度拟真战斗** —— 真实弹道、肢体血量、状态效果、改枪
5. **风险/回报动态曲线** —— 玩家在"贪"与"撤"之间持续拉扯

### 0.3 霓虹废墟的差异化定位
- **俯视角 2D + 像素艺术 + 零依赖** → 决定了我们走"轻量 + 美学 + 易传播"路线
- **对标塔科夫的不是弹道拟真，而是"局内外绑定"与"资产博弈"的系统设计**
- **不抄硬核死亡惩罚** → 借鉴其机制，提供"分级风险"（保险箱 / 保险 / 角色槽位）
- **学习《暗区突围》《三角洲行动》的轻量化** → 局时长 8-15 分钟，单图资产量适中

### 0.4 对标策略总结
| 维度 | 塔科夫做法 | 霓虹废墟做法 | 目标 |
|------|-----------|-------------|------|
| 死亡惩罚 | 装备 100% 丢失 | 装备丢失 + 保险返还 + 保险箱保留 | 降低挫败感、保留张力 |
| 局时长 | 30-45 分钟 | 8-15 分钟 | 移动端友好 |
| 改枪深度 | 100+ 配件 | 5 类配件、20+ 选项 | 简化但保留深度 |
| 弹道 | 真实物理 | 抛物线 + 穿透 + 击退 | 拟真感 + 玩法性 |
| 经济循环 | 9 个商人 + 黑市 | 3 NPC + 仓库 + 任务 | 闭环但易理解 |
| 局外成长 | 藏身处 + 技能树 | 基地设施 + 角色等级 | 长期目标感 |

## 一、对标核心系统详解（与现状对照）

### 1.1 局内外绑定系统

**塔科夫原版：**
- 带入战局 = 动用仓库资产；带出 = 归仓；死亡 = 永久丢失（非保险箱部分）
- `Find in Raid` 状态：只有"局内搜出且带出"的物品才有特殊标记

**当前霓虹废墟状态（v1.0）：**
- ✅ 已有 `STASH.items[]` 仓库 + `G.player.inventory` 本局背包
- ✅ 撤离成功 → 物品入库（`withdrawFromStash` / `depositToStash`）
- ❌ 缺少"死亡惩罚分层"（无保险箱概念）
- ❌ 缺少"Find in Raid"标记
- ❌ 缺少"装备保险"机制

**v1.4 改造方案：**

| 子系统 | 实现 | 优先级 |
|--------|------|-------|
| 保险箱 `SecureContainer` | 玩家开局 2x2 槽位（升级到 3x3），死亡必定带出 | 🔴 P0 |
| 装备保险 `Insurance` | 战局开始时可选投保（消耗战前资金），若该局全 PMC 撤离且玩家已死，装备 12-24h 后邮件返还 | 🔴 P0 |
| FiR 标记 | 局内搜出的物品打上 `fir: true` 标签；只有 FiR 物品可上架"跳蚤市场" | 🟡 P1 |
| 死亡惩罚分级 | 主武器/副武器/背包 100% 丢；护甲耐久度损失 50%；消耗品全丢 | 🟡 P1 |

### 1.2 资产博弈系统

**塔科夫原版：**
- "Gear Fear" 心理 —— 玩家对装备的估值 = 投入时间 × 金钱
- 三种玩家原型：Rat（鼠）、Chad（壮汉）、Casual（休闲）
- 价值密度（value/weight）决策是核心玩法

**当前霓虹废墟状态（v1.0）：**
- ✅ 已有 `lootValue` 价值累积
- ✅ 撤离条件 `lootValue ≥ 120`
- ❌ 没有"撤离点动态选择"
- ❌ 没有"负重与价值的紧张关系"

**v1.4 改造方案：**

| 子系统 | 实现 | 优先级 |
|--------|------|-------|
| 价值密度显示 | UI 显示 `物品价值 / 重量`，高密度优先提示 | 🟡 P1 |
| 动态撤离点 | 每局 3-5 个撤离点，部分需条件激活（`lootValue > 阈值`/持有特定钥匙） | 🔴 P0 |
| Greed Separatrix（贪欲分界） | 服务端校验：基于玩家"价值×时间"动态显示"建议撤离"提示 | 🟢 P2 |
| 三种玩家路线 | 文档化引导：鼠路线（走暗道、避战）、壮汉路线（穿重甲清场）、休闲路线（中等装混战） | 🟢 P2 |

### 1.3 封闭循环经济

**塔科夫原版：**
- 9 个商人（Prapor/Therapist/Skier/Peacekeeper/Mechanic/Ragman/Jaeger/Fence/Ref）
- 每件"垃圾"都能通过商人 barter（物物交换）变成有用物
- Fence 作为"熵池"，吸收玩家装备流动

**当前霓虹废墟状态（v1.0）：**
- ❌ 没有商人系统
- ❌ 没有"物物交换"
- ✅ 有"战利品加权随机表" `LOOT_POOL`

**v1.5 改造方案（商人系统）：**

3 个 NPC 商人，各有特色：

| 商人 | 主题 | 主要商品 | 偏好物品 |
|------|------|---------|---------|
| **Raven（武器商）** | 军火/改装 | 武器、配件、弹药 | 枪械、弹药、电子元件 |
| **Vega（医疗商）** | 药品/消耗品 | 医疗包、注射器、buff | 药品、化学品 |
| **Cipher（黑市）** | 信息/稀有 | 钥匙卡、情报、稀有装备 | FiR 标记物、稀有战利品 |

商人系统规格：
- **3 级好感度**（陌生人/熟人/挚友）→ 解锁等级商品
- **每日 4 个商品**（基于 `hash2d(date)` 确定性刷新）
- **任务驱动升级**：完成商人专属任务提升好感度
- **物物交换 (Barter)**：可用低级物品换高级物品（如 10×9mm + 1×金属零件 → 1×消音器）

### 1.4 战斗深度系统

**塔科夫原版：**
- 真实弹道：飞行时间、弹道下坠、跳弹、穿透
- 肢体血量：头/胸/腹/双臂/双腿分别计算
- 状态效果：断肢、骨折、出血、缺氧、中毒
- 武器改装：100+ 配件、影响后坐力/精度/消音/射程

**当前霓虹废墟状态（v1.0）：**
- ✅ 已有 7 种武器、后坐力累加/衰减、子弹物理（速度、射程、穿透、掩体阻挡）
- ✅ 已有爆头机制（v1.1 待加）、状态效果（眩晕/致盲/燃烧）
- ❌ 弹道下坠较弱
- ❌ 肢体血量未区分
- ❌ 武器改装系统未实现

**v1.5-v1.6 改造方案：**

| 子系统 | 实现 | 优先级 | 拟落版本 |
|--------|------|-------|---------|
| 弹道下坠增强 | 子弹 y += 0.02 * dist（俯视角中体现抛物线） | 🟡 P1 | v1.5 |
| 肢体血量 | `hp = { head, thorax, stomach, armL, armR, legL, legR }` | 🟡 P1 | v1.6 |
| 状态效果深化 | 出血(持续掉血+可止血)、骨折(移速-30%)、失明(HUD遮罩) | 🟡 P1 | v1.6 |
| 武器配件 5 类 | 瞄具(红点/全息/2x/4x)、枪口(消音/制退/补偿)、握把、弹匣(扩容/快速)、枪托 | 🔴 P0 | v1.5 |
| 弹药细分 | 穿甲(对甲+50%)、空尖(对血肉+30%)、亚音速(降警戒) | 🟡 P1 | v1.5 |

### 1.5 风险/回报动态曲线

**塔科夫原版：**
- 高价值区 = 高 AI 密度 + 高玩家遭遇率
- 时间越长，场上玩家越少，剩余者价值越高（"末期红利"）
- 撤离点附近是"最后博弈区"（PVP 高发）

**当前霓虹废墟状态（v1.0）：**
- ✅ 已有 3 个撤离点，5 秒停留机制
- ❌ 没有"价值热点 → 危险热点"的设计
- ❌ 没有"末期红利"机制

**v1.4 改造方案：**

| 子系统 | 实现 | 优先级 |
|--------|------|-------|
| 价值热点系统 | 地图分区域，金库/实验室/武器库价值高，敌人密度+2 倍 | 🔴 P0 |
| 时间压力 | 战局有 12 分钟倒计时，时间越久可见 HUD 警示（AI 增援） | 🟡 P1 |
| 末期红利 | 最后 3 分钟撤离点奖励 +50% 价值 | 🟢 P2 |
| 撤离点博弈 | 撤离点附近制造"最后遭遇区"（高草丛、狭窄入口） | 🟡 P1 |

## 三、详细开发路线图（对标塔科夫）

### 阶段一：核心机制深化（v1.4 - v1.5，约 3-4 个月）

#### v1.4 局内外强绑定（核心 P0）
**目标：建立"资产博弈"心理引擎**

| 任务 | 规格 | 工作量 | 验收 |
|------|------|-------|------|
| 保险箱 `SecureContainer` | 玩家仓库中独立 2x2 槽位，本局带入时死亡必带出；可解锁升级到 3x3 | 3 天 | 死亡测试：保险箱内物品回仓 |
| 装备保险 `Insurance` | 战局开局可勾选 1-3 件装备投保，消耗金币；该局所有 PMC 撤离后 12-24h 邮件返还 | 5 天 | 投保后死亡且全撤离，邮件收到装备 |
| FiR 标记 | 局内搜出物品打 `fir: true` 标签；死亡后所有 FiR 物品变非 FiR | 2 天 | 测试局内搜出→带出→入库，状态保留 |
| 死亡惩罚分级 | 主武/副武/背包 100% 丢；护甲 50% 耐久度损失；消耗品全丢；保险箱保留 | 3 天 | 死亡后检查各类物品归宿 |
| 价值密度 UI | 物品 tooltip 显示 `value/weight` 比率，红黄绿三色 | 2 天 | 拾取不同物品显示密度 |
| 动态撤离点 | 3-5 个撤离点，部分需 `lootValue > X` 激活，部分需特殊钥匙 | 4 天 | 不同价值/钥匙显示不同撤离点 |
| 邮件系统 `Mail` | 跨局延时消息：保险返还、商人交易、任务奖励 | 4 天 | 死亡+保险后查看邮件 |

**v1.4 验收标准：**
- [ ] 玩家在战局中死亡 100 次，统计"重要装备保留率 ≥ 30%"（保险箱+保险）
- [ ] 玩家有明确"贪"与"撤"的决策点（价值密度 + 撤离点条件）
- [ ] localStorage 存档格式向后兼容（带版本号）

#### v1.5 商人与经济（核心 P0）
**目标：建立封闭循环经济**

| 任务 | 规格 | 工作量 | 验收 |
|------|------|-------|------|
| 商人系统框架 | 3 NPC（Raven/Vega/Cipher），各 3 级好感度 | 5 天 | 仓库 UI 可访问商人 |
| 商品每日刷新 | 基于 `hash2d(date)` 确定性刷新，每个商人 4 商品 + 2 barter 配方 | 3 天 | 跨日检查商品变化 |
| 物物交换 Barter | `barterRecipes[]` 定义 20+ 配方（如 5×铁 + 3×布 → 1×急救包） | 4 天 | 持有材料时显示可 barter |
| 商人任务 | 每商人 3-5 条任务线，提升好感度 | 5 天 | 完成任务后解锁新商品 |
| 货币系统 | `credits` 货币（取代直接的"价值"），交易更直观 | 2 天 | 击杀敌人获得 credits |
| 黑市赌博 | Cipher 提供 3 种武器箱（500/1500/5000 credits），开启有动画 | 3 天 | 赌博有视觉反馈 |

**v1.5 验收标准：**
- [ ] 玩家可通过"战利品 → 卖商人 → 买装备 → 进战局"完成经济循环
- [ ] 至少 20 种 barter 配方，玩家有"垃圾变宝"体验
- [ ] 商人每日刷新确定性（同一天任何玩家看到的商品一致）

#### v1.6 战斗深度（核心 P1）
**目标：建立塔科夫级战斗深度**

| 任务 | 规格 | 工作量 | 验收 |
|------|------|-------|------|
| 武器配件系统 | 5 类配件槽：瞄具/枪口/握把/弹匣/枪托；20+ 配件定义 | 7 天 | 拾取配件可装备，武器属性变化 |
| 弹药细分 | 4 种弹药类型：标准/穿甲/空尖/亚音速；不同弹药不同属性 | 4 天 | 携带不同弹药对敌人伤害不同 |
| 弹道下坠 | 子弹 y += 0.02 * dist，200 距离后明显下坠 | 2 天 | 远距离射击需抬高 |
| 肢体血量细化 | `hp: { head, thorax, stomach, armL, armR, legL, legR }` | 5 天 | 不同部位受伤不同效果 |
| 状态效果深化 | 出血(止血剂可治)、骨折(夹板可治)、失明(治疗剂) | 4 天 | 状态效果有视觉和治疗路径 |
| 护甲耐久度 | 护甲有 HP 槽，受击降低，0 时失效 | 3 天 | 反复受击护甲破损 |

**v1.6 验收标准：**
- [ ] 同一把武器换不同配件，伤害/精度/后坐力有显著差异
- [ ] 玩家在战斗中需考虑弹药选择（穿甲 vs 火力）
- [ ] 状态系统提供更多战术选择（止血 vs 强攻）

### 阶段二：内容扩展（v1.7 - v1.8，约 2-3 个月）

#### v1.7 藏身处 + 角色卡组
**目标：建立长期目标感**

| 任务 | 规格 | 工作量 |
|------|------|-------|
| 藏身处地图 | 5 个设施槽：医疗站/工作台/情报中心/健身房/仓库 | 5 天 |
| 设施升级树 | 每设施 5 级，需要材料组合；升级解锁能力 | 7 天 |
| 角色卡组 `Loadout` | 玩家可保存 3 套卡组（武器+装备+消耗品），快速选择开局 | 3 天 |
| 跨卡组继承 | 1 个卡组带进战局，2 个留在仓库作为"备用" | 2 天 |
| 任务板 | 每日/每周任务（"用狙击枪击杀 5 敌人"、"不耗血撤离"等） | 4 天 |
| 仓库扩容 | 20 → 30 → 40 → 50 → 60 格的付费扩容 | 2 天 |

#### v1.8 多地图 + 敌人类型
**目标：内容多样性**

| 任务 | 规格 | 工作量 |
|------|------|-------|
| 多地图支持 | 3 张地图（城区废墟/地下设施/工业厂区），每图独立种子 | 7 天 |
| Boss 敌人 | 3 个 Boss，每 5 局出现一次，独特机制 | 6 天 |
| 无人机敌人 | 飞行单位、可被击落、绕掩体 | 4 天 |

## 五、技术债务与重构

### 5.1 当前已知问题
1. **game.js 已 6760 行** → 单文件约束下，用 IIFE 模拟模块化（`// === 模块名 ===`）
2. **状态机分支过长** → 拆分为独立子函数（`doPatrolState`、`doChaseState`）
3. **粒子/伤害/爆炸有重复代码** → 提取 `applyAreaDamage(x, y, r, dmg, owner)` 通用函数
4. **`drawPlayer` / `drawEnemy` 重复** → 提取 `drawPixelHuman(opts)` 框架
5. **音频/UI/战斗/AI 混在一个 IIFE** → 分章节注释（`// === 战斗系统 ===`）

### 5.2 重构优先级
| 优先级 | 任务 | 收益 |
|--------|------|------|
| 🔴 P0 | 提取 `applyAreaDamage` 通用函数 | 减少 ~200 行 |
| 🔴 P0 | `drawPixelHuman` 通用绘制 | 减少 ~300 行 |
| 🟡 P1 | 武器系统数据驱动 | 新增武器只需改配置 |
| 🟡 P1 | 商人系统独立模块（注释块） | v1.5 准备 |
| 🟡 P1 | 物品系统 `ItemDef` 数据驱动 | v1.5 准备 |
| 🟢 P2 | Canvas 分层渲染（地面/实体/效果/UI） | 性能 +10% |

### 5.3 性能目标
- 60fps @ 1080p（核心目标）
- 低端设备 ≥ 30fps
- 实体上限：敌人 30、子弹 200、粒子 500、地上物品 100
- 启用对象池（避免频繁 `new`/`delete`）
