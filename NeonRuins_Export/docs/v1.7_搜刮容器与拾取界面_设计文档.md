# v1.7 子系统设计：搜刮容器与拾取界面

> **子系统代号**：LOOT-UI  
> **对标项目**：《逃离塔科夫》搜刮机制 + 霓虹废墟 v1.0 基线  
> **目标读者**：项目主理 / AI 协作开发  
> **设计原则**：界面要像「在废墟里翻找战利品」而不是「打开宝箱菜单」  
> **核心约束**：保持霓虹废墟的「低饱和度电影感 + 青色霓虹点缀 + 像素艺术」整体风格  
> **文档版本**：v1.0  
> **编制日期**：2026-06-13

---

## 0. 背景与目标

### 0.1 现状问题
当前 v1.0 的搜刮体验（基于 [game.js:1748-1812](file:///workspace/SDC/game.js#L1748-L1812)）：

- **机制**：`按 E` → 1.2 秒进度条 → 物品**直接散落容器周围地面** → 玩家走过去一个个拾取
- **痛点**：
  1. 缺乏"选宝"决策 —— 物品全部直接掉地上，没有"挑三拣四"的紧张感
  2. 拾取是**一次性全部**的，没有"留一些/拿一些"的策略
  3. 散落物容易被忽略（视野、敌人干扰时漏看）
  4. 价值密度没有视觉提示（玩家不知道"值不值"）
  5. 缺乏塔科夫式"开箱仪式感"

### 0.2 设计目标
1. **保留长按搜刮动画**（1.2 秒不动）→ 维持"半盲"压力
2. **增加搜刮完成后的拾取界面**（塔科夫式物品列表）→ "选宝"决策
3. **差异化容器种类**（3 种普通 + 1 种隐藏金库 + 1 种 AI 玩家尸体）→ 风险/回报曲线
4. **保持霓虹废墟整体风格**（像素 / 青色霓虹 / 低饱和度）→ 不破坏沉浸感
5. **保持单文件架构 + 零依赖** → 不引入外部库

### 0.3 不做的事
- ❌ 不做塔科夫式网格背包拖拽（俯视角 2D 复杂度太高）
- ❌ 不做真实 PvP（用户明确要求"做单机"）
- ❌ 不改存档格式（保持 localStorage 兼容）
- ❌ 不破坏现有 1.2 秒搜刮动画（保留"半盲"压力）

## 1. 系统总览

### 1.1 玩家流程
```
玩家走近容器
  ↓ (按 E)
长按 1.2 秒搜刮（保持不动，取消条件：移动/开火/离开范围）
  ↓ (搜刮完成)
容器打开动画 + 粒子爆发（已存在）
  ↓
【新增】弹出"拾取界面" overlay（半屏、不暂停游戏）
  ↓
玩家在界面中点击单个物品 → 拾取进本局背包
  ↓
点击"全部拾取"或"关闭" → 界面消失
  ↓
游戏中：物品已在本局背包，可在 TAB 库存页查看
```

### 1.2 数据流
```
[E 按下]
  ↓
tryInteract() 找到最近容器
  ↓
G.looting = { container, startAt, duration: 1200 }
  ↓
[每帧 updateLooting()]
  ↓
elapsed >= 1.2s ?
  ↓ 是
openContainer(container)  [现有逻辑] 标记 opened
  ↓
G.lootWindow = {           [新增]
    containerId: c.id,
    items: rollLoot(n),    // 物品列表
    startAt: now
  }
  ↓
renderLootWindow()         [新增] 渲染拾取界面
```

### 1.3 关键设计决策
| 决策点 | 选择 | 理由 |
|--------|------|------|
| 拾取界面是否暂停游戏 | ❌ 不暂停 | 保留紧张感；半透明 overlay 让玩家看到周围 |
| 拾取界面位置 | 屏幕底部弹窗 | 不挡主角和敌人 |
| 单次拾取 | 点击/点击 + 自动拾取 | 玩家自主选择 |
| 拾取后物品消失 | 是 | 进本局背包 |
| 容器内物品持久性 | 战局内有效 | 战局结束清空 |
| 价值/重量排序 | 简单 toggle | 玩家有"价值密度"决策 |

## 2. 容器种类与差异化机制

### 2.1 三种普通容器（取代现有 4 种）

| 类型 | 名称 | 视觉 | 产出 | 风险 | 数量/局 |
|------|------|------|------|------|---------|
| **Crate** | 生锈货箱 | 矩形铁箱 + 锈迹 | 2-4 件（70% 普通、25% 稀有、5% 极稀有） | 低 | 10-12 |
| **Vending** | 废弃售货机 | 玻璃面板 + 昏暗光 | 1-2 件（含消耗品/弹药） | 低 | 4-5 |
| **Debris** | 废墟堆 | 不规则岩石 + 金属 | 2-3 件（70% 杂物、20% 电子元件、10% 稀有） | 中（靠近易被伏击） | 4-6 |

> **删除项**：原"补给箱"合并入"生锈货箱"（外观略变），避免种类过多视觉杂乱。

### 2.2 隐藏金库（新增）

| 项目 | 说明 |
|------|------|
| **名称** | 霓虹金库 / Neon Cache |
| **外观** | 青色霓虹边框的小型密封舱（隐蔽，不打开时几乎不可见） |
| **生成** | 每局随机 1-2 个，位置远离玩家出生点 |
| **激活条件** | 玩家必须持有「解码芯片」（可在废墟堆中搜出，~5% 概率） |
| **产出** | 1 件高价值物品（武器/稀有元件/护甲 T2/插件） |
| **视觉反馈** | 玩家靠近时若未持有解码芯片，HUD 提示"需解码芯片" |
| **生成概率** | `hash2d(seed, 12, 88) < 0.15` 决定该格是否生成 |

### 2.3 AI 玩家尸体（新增，模拟 PvP 体验）

| 项目 | 说明 |
|------|------|
| **名称** | 拾荒者遗骸 / Scavenger Remains |
| **外观** | 倒地人物剪影 + 散落装备（保持像素风） |
| **生成** | 每局 2-3 个，固定位置（基于 `hash2d` 确定性） |
| **背景** | 单机模式下，这些是"上一个撤离失败的拾荒者"留下的（lore 包装） |
| **产出** | 模拟"上一局玩家卡组"：1 主武（随机品质）、1 护甲、3-5 件消耗品/杂物 |
| **风险** | 周围通常有 1-2 个敌人埋伏（增加 PvP 体验感） |
| **拾取** | 同普通容器 |

### 2.4 容器属性数据结构
```javascript
// 替换或扩展 createContainer
{
    id: 'crate_001',         // 唯一 ID
    type: 'crate' | 'vending' | 'debris' | 'cache' | 'corpse',
    x, y, w, h,
    color,                    // 主体色
    label,                    // 显示文字
    opened: false,            // 是否已开
    
    // === 新增 ===
    contents: [],             // 搜刮前的物品列表（[ {key, qty, value, weight, kind} ]）
    searched: false,          // 是否搜刮完成（容器已搜但 UI 未关闭）
    lockType: 'none' | 'decoder' | 'lockpick',  // 锁定类型
    enemyGuard: null,         // 关联的埋伏敌人 id（尸体容器专属）
    
    // === 兼容旧字段 ===
    lootCount: 0,
    lootLeft: 0,
    isContainer: true
}
```

### 2.5 视觉差异化
| 容器 | 主色 | 边框光 | 标识 | 玩家靠近时提示 |
|------|------|--------|------|---------------|
| Crate | `#4a3f33`（锈棕） | 无 | "货箱" | "按 E 搜刮" |
| Vending | `#3c4854`（冷灰） | 微弱琥珀 | "售货机" | "按 E 搜刮" |
| Debris | `#3a3b40`（石灰） | 无 | "废墟堆" | "按 E 搜刮" |
| Cache | `#1e2a30` + `#5ec8e0` 霓虹边 | **强霓虹青色脉冲** | "霓虹金库" | "需解码芯片" / "按 E 开启" |
| Corpse | `#3a2a2a`（血红）+ 倒地剪影 | 无 | "拾荒者遗骸" | "按 E 搜刮" |

> **关键**：金库的霓虹脉冲是唯一打破"低饱和度"约束的地方 —— 用 v1.0 已有的 `--neon-cyan: #5ec8e0` 实现。

## 3. 拾取界面（LOOT WINDOW）详细设计

### 3.1 视觉规范
- **位置**：屏幕底部 30% 区域
- **宽度**：720px（最大 90% 屏宽）
- **高度**：自适应内容（280-360px）
- **背景**：`rgba(10, 12, 15, 0.92)` + 青色霓虹边框（1px solid `var(--neon-cyan)`）
- **角落装饰**：复用 `.menu-box::before/::after` 的青色 L 形角标
- **模糊效果**：`backdrop-filter: blur(6px)`，让游戏世界在背景中可见

### 3.2 布局
```
┌──────────────────────────────────────────────────┐
│  [容器图标] 生锈货箱 · 5 件物品      [X] 关闭    │  ← 标题栏 40px
├──────────────────────────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐   │
│  │ 🔋  │ │ 💊  │ │ 9mm  │ │ ✦   │ │ 破片 │   │  ← 物品列表
│  │ ×3   │ │ ×1   │ │ ×12  │ │ ×1   │ │ ×2   │   │     网格 5 列
│  │ 22   │ │ 30   │ │ 5    │ │ 40   │ │ 25   │   │
│  │ v/0.3│ │ v/0.5│ │ v/0.1│ │ v/0.2│ │ v/0.4│   │  ← 价值/重量密度
│  └──────┘ └──────┘ └──────┘ └──────┘ └──────┘   │
│                                                  │
│  [悬停详情面板 - 显示物品描述/价值/属性]         │  ← 详情 60px
├──────────────────────────────────────────────────┤
│  [价值排序] [重量排序] [价值密度]    [全部拾取]  │  ← 操作栏 50px
└──────────────────────────────────────────────────┘
```

### 3.3 物品卡片（Item Card）
| 属性 | 说明 |
|------|------|
| 尺寸 | 96×96px |
| 背景 | `rgba(20, 24, 30, 0.7)` + 1px 青色虚线边框 |
| 悬停 | 背景亮 + 青色实线边框 + 上移 2px + 发光 |
| 选中 | 琥珀色边框 + 强发光（已拾取） |
| 内容 | 物品 emoji（16px） + 名称（10px） + 数量（右下） + 价值（底部）+ 价值密度色条 |
| 颜色编码 | 普通=灰白、稀有=紫、武器=粉、护甲=蓝白、极稀有=脉冲紫 |

**价值密度色条**（关键设计）：
- 顶部一条 2px 高的细线，颜色：
  - 🟢 绿色 `#7aaa6a`（密度 ≥ 50）
  - 🟡 黄色 `#d8a45c`（密度 20-50）
  - 🔴 暗红 `#b85a6e`（密度 < 20，红色但用 `b85a6e` 而非 `ff0000`，符合色彩规范）

### 3.4 交互规则
| 操作 | 效果 |
|------|------|
| 单击物品 | 拾取该物品 → 进本局背包 → 该卡片变暗"已拾取"状态 |
| 双击物品 | 拾取并自动关闭界面 |
| 鼠标悬停 | 顶部详情面板显示该物品的描述/价值/重量 |
| 鼠标右键物品 | 显示"丢弃"（仅本界面内，不进背包） |
| 点击"全部拾取" | 全部进背包（若背包满，提示哪几个装不下） |
| 点击"X"或 ESC | 关闭界面，剩余物品消失（不在场景中保留） |
| 点击"价值排序" | 按 value 降序 |
| 点击"重量排序" | 按 weight 升序 |
| 点击"价值密度" | 按 value/weight 降序（默认） |

### 3.5 状态机
```javascript
// G.lootWindow
{
    state: 'closed' | 'open' | 'closing',
    containerId: string,
    items: [
        {
            uid: string,            // 唯一 ID
            defKey: string,         // ITEM_TYPES 的 key
            qty: number,
            picked: boolean,        // 是否已拾取
        },
        ...
    ],
    hoverUid: string | null,
    sortBy: 'density' | 'value' | 'weight',
}
```

### 3.6 视觉与游戏世界的衔接
- 容器开启动画（粒子爆发）**继续播放**（1-2 秒）
- 拾取界面**不暂停游戏**，敌人可以继续巡逻、战斗
- 拾取界面半透明 + 模糊，让玩家隐约看到：
  - 玩家角色轮廓
  - 接近的敌人（如果有）
  - 投影的搜索动画
- **关键防作弊**：游戏循环中持续检查 `G.lootWindow` 状态，但 update/render 仍运行

### 3.7 拾取反馈
- 拾取瞬间：物品卡片播放"吸入"动画（缩小 + 淡出 + 粒子向角色飞）
- 顶部 HUD `lootValue` 实时更新（已有）
- 音效：复用现有 `Sound.loot()`（柔和铃音）
- 物品稀有时：特殊音效 + 卡片发光 1 次

```javascript
    const pool = POOLS[type];
    const out = [];
    for (let i = 0; i < n; i++) {
```

```javascript
function showLootWindow(c) {
    G.lootWindow = {

    document.getElementById('loot-title-text').textContent = c.label;

}

function hideLootWindow() {
    if (!G.lootWindow) return;
    G.lootWindow.state = 'closing';
    document.getElementById('loot-window').classList.add('hidden');
    setTimeout(() => { G.lootWindow = null; G.lootWindow && (G.lootWindow.state = 'closed'); }, 250);
}

function renderLootWindow() {
    if (!G.lootWindow) return;
    const w = G.lootWindow;
    const grid = document.getElementById('loot-grid');
    grid.innerHTML = '';

    // 排序
    const items = [...w.items];
    const sortFns = {
        value:   (a, b) => (ITEM_TYPES[b.defKey].value * b.qty) - (ITEM_TYPES[a.defKey].value * a.qty),
        weight:  (a, b) => ITEM_TYPES[a.defKey].weight - ITEM_TYPES[b.defKey].weight,
        density: (a, b) => {
            const da = ITEM_TYPES[a.defKey].value / Math.max(0.01, ITEM_TYPES[a.defKey].weight);
            const db = ITEM_TYPES[b.defKey].value / Math.max(0.01, ITEM_TYPES[b.defKey].weight);
            return db - da;
        }
    };
    items.sort(sortFns[w.sortBy] || sortFns.density);

    for (const it of items) {
        const def = ITEM_TYPES[it.defKey];
        const card = document.createElement('div');
        const density = def.value / Math.max(0.01, def.weight);
        const densityColor = density >= 50 ? '#7aaa6a' : density >= 20 ? '#d8a45c' : '#b85a6e';
        const kindClass = (def.kind === 'weapon' || def.kind === 'armor' || def.kind === 'loot') ? def.kind : '';
        card.className = `loot-card ${kindClass} ${it.picked ? 'picked' : ''}`;
        card.dataset.uid = it.uid;
        card.innerHTML = `
            <div class="card-density" style="background:${densityColor}"></div>
            <div class="card-icon">${def.icon || def.label.slice(0, 1)}</div>
            <div class="card-name">${def.label}</div>
            <div class="card-value">${def.value * it.qty} 点</div>
            ${it.qty > 1 ? `<div class="card-qty">×${it.qty}</div>` : ''}
        `;
        card.addEventListener('click', () => pickLootItem(it.uid));
        card.addEventListener('mouseenter', () => showLootDetail(it));
        grid.appendChild(card);
    }

    // 更新 sort 按钮状态
    document.querySelectorAll('.loot-sort-btn').forEach(b => {
        b.classList.toggle('active', b.dataset.sort === w.sortBy);
    });
}

function pickLootItem(uid) {
    if (!G.lootWindow) return;
    const it = G.lootWindow.items.find(x => x.uid === uid);
    if (!it || it.picked) return;

    const def = ITEM_TYPES[it.defKey];
    const p = G.player;

    // === 背包空间检查 ===
    const cur = p.inventory[it.defKey] || 0;
    p.inventory[it.defKey] = cur + it.qty;
    G.lootValue += def.value * it.qty;

    // FiR 标记（v1.4 规划）
    if (G.firItems) G.firItems.add(`${it.defKey}_${Date.now()}_${Math.random()}`);

    it.picked = true;
    Sound.loot();
    renderLootWindow();
    updateHudLootText();  // 已有函数

    // 拾取动画（粒子飞向角色）
    spawnParticles(G.player.x, G.player.y, def.color || C.loot, 8, 80);
}

function pickAllLootItems() {
    if (!G.lootWindow) return;
    for (const it of G.lootWindow.items) {
        if (!it.picked) pickLootItem(it.uid);
    }
}

function showLootDetail(it) {
    if (!G.lootWindow) return;
    const def = ITEM_TYPES[it.defKey];
    const density = (def.value / Math.max(0.01, def.weight)).toFixed(1);
    const detail = document.getElementById('loot-detail');
    detail.innerHTML = `
        <div class="loot-detail-name">${def.label}</div>
        <div>
            <span class="loot-detail-stat">价值 <b>${def.value * it.qty}</b> 点</span>
            <span class="loot-detail-stat">重量 <b>${(def.weight * it.qty).toFixed(2)}</b> kg</span>
            <span class="loot-detail-stat">密度 <b>${density}</b></span>
            <span class="loot-detail-stat">种类 <b>${def.kind}</b></span>
        </div>
        <div class="loot-detail-desc">${def.desc || '战前时代的遗物，仍有使用价值。'}</div>
    `;
}
```

#### `tryInteract()` 关键修改（金库解码）
```javascript
function tryInteract() {
    const p = G.player;
    const now = performance.now();
    // 优先：撤离 > 拾取地面 > 搜刮容器

    // === 修改：搜刮容器逻辑 ===
    let nearestC = null, best = 999;
    for (const c of G.containers) {
        if (c.opened) continue;
        const d = dist(p, c);
        if (d < 70 && d < best) { best = d; nearestC = c; }
    }
    if (nearestC && !G.looting) {
        // === 新增：金库解码检查 ===
        if (nearestC.lockType === 'decoder') {
            if ((p.inventory.decoder || 0) < 1) {
                showHint('需解码芯片', 1500);
                return;
            }
            p.inventory.decoder -= 1;
            // 解码音效
            Sound.loot();
        }
        G.looting = { container: nearestC, startAt: now, duration: 1200 };
    }
}
```
